1. Introduction

Welcome to the PixOLine documentation. This guide explains the basic workflow for creating and editing designs using PixOLine on Android.

PixOLine provides a simple workspace where you can combine text, images, shapes, colors, and other visual elements to create your own designs.

If you are using PixOLine for the first time, we recommend following these tutorials in order.

📱

Android Workspace

Create and edit your projects directly from your Android phone or tablet.

🎨

Creative Tools

Add text, images, shapes, colors, and other elements to your projects.

2. Create a New Project

The first step in creating a design is to start a new project. A project acts as the workspace for your artwork.

1

Open PixOLine

Launch PixOLine from your Android device and open the project screen.

2

Select New Project

Tap the option for creating a new project. You may then be asked to select your preferred canvas size.

3

Choose a Canvas

Select an appropriate canvas size for your project. Choose a larger canvas when creating designs that require more detail.

Tip: Think about where your design will be used before choosing the canvas size. A social media post, banner, and printable poster may require different dimensions.

3. Understanding the Interface

The PixOLine workspace contains several areas that help you create and edit your design.

Area Purpose
Canvas The main area where your design is created.
Toolbar Provides access to common editing and design tools.
Layers Helps organize and manage individual design elements.
Properties Allows you to adjust selected elements.

4. Adding Text

Text is useful for titles, captions, labels, announcements, posters, and many other types of designs.

Add a Text Element

1

Select the Text tool from the toolbar.

2

Tap or drag on the canvas to create a text area.

3

Enter your text and adjust the available text settings.

Useful Text Settings

  • Font family and font style.
  • Font size.
  • Text color.
  • Alignment.
  • Position and size.
  • Spacing and other available formatting options.

5. Adding Images

Images can be imported from your device and placed inside your design.

1

Choose Import Image

Open the image or media import option from the PixOLine toolbar.

2

Select an Image

Choose an image from your device gallery or supported file location.

3

Position the Image

Resize, move, and position the image according to your design.

Note: Very large images may require additional memory and processing time on mobile devices.

6. Shapes & Colors

Shapes can be used to create backgrounds, buttons, decorative elements, borders, and other visual components.

Working With Shapes

  • Select the Shapes tool.
  • Choose the shape you want to add.
  • Place the shape on your canvas.
  • Resize or reposition the shape.
  • Adjust its color and other available properties.

Choosing Colors

Use colors that complement the purpose of your design. For example, a promotional graphic may use strong contrasting colors while a professional presentation may benefit from a more restrained palette.

7. Working With Layers

Layers help organize multiple elements in a project. Understanding layers becomes especially important when working on more complex designs.

Layer Order

Elements higher in the layer order may appear above elements underneath them. You can change the order when one object needs to appear behind or in front of another.

Background → Image → Shape → Text → Decorative Element

A well-organized layer structure can make editing easier and help prevent accidental changes to other elements.

8. Saving a Project

Save your project regularly while working so you can continue editing it later.

1

Open the project menu or save option.

2

Enter a meaningful project name.

3

Confirm the save operation and wait for the project to finish saving.

Best Practice: Keep backup copies of important projects, especially before making major changes to your device.

9. Export Your Design

When your design is finished, export it into a supported image or document format.

Before Exporting

  • Check that all design elements are positioned correctly.
  • Review text for spelling mistakes.
  • Make sure images are displayed correctly.
  • Confirm that your device has enough available storage.

Export Process

Open the export option from the project menu, select your preferred output format, and confirm the export.

Tip: If an exported file is difficult to find, check your Downloads, Pictures, Documents, or the folder selected during the export process.

10. Share Your Design

After exporting your design, you can use Android's sharing options to send your artwork to other applications.

Depending on your device, you may be able to share your exported design through messaging applications, email, cloud storage, social media applications, or other compatible services.

11. Troubleshooting

PixOLine feels slow

Close applications running in the background and restart PixOLine. Large projects and high-resolution images may require additional device resources.

An image will not import

Check that the image exists on your device and that PixOLine has the required permissions. Try another image to determine whether the problem is specific to the file.

My project will not open

Verify that the project file has not been moved, renamed, deleted, or damaged. If possible, try opening a backup copy.

Export is not working

Check available storage and application permissions. Trying a smaller or simpler project can also help identify whether the issue is related to project complexity.

Still need help? Visit our Support page or Contact Us page for additional assistance.

12. Next Steps

You now have an overview of the basic PixOLine workflow. The best way to learn is to experiment with different tools and create small projects.

  • Create a simple social media graphic.
  • Experiment with different fonts and colors.
  • Import an image and combine it with text.
  • Try arranging multiple layers.
  • Export your finished project.

Happy creating! Explore PixOLine, experiment with the tools, and turn your ideas into finished designs.
