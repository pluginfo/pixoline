# 🎨 Graphic Design App

A simple and powerful graphic design app for Android that helps users create beautiful graphics directly from their mobile devices.

## ✨ Features

* 🎨 Easy-to-use graphic design tools
* 🖼️ Create custom graphics and designs
* ✏️ Add and customize text
* 🔷 Add shapes and design elements
* 🌈 Customize colors and backgrounds
* 📱 Mobile-friendly and easy-to-use interface
* 💾 Save and export your designs
* ⚡ Fast and lightweight

## 📱 About

This project is an Android graphic design application designed to make graphic creation simple, fast, and accessible.

Users can create and customize different types of visual content directly from their smartphones without needing complicated design software.

The project also includes a static website hosted with GitHub Pages, providing information about the application and its features.
